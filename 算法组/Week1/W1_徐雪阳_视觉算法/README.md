测试图2比测试图1更加好，因为测试图2的背景为纯白色，效果更好
测试图3中部分背景转化成白色，背景颜色越多越复杂越可能被误检，轮廓提取也有一点偏差
1. HSV范围 `HSV_LOW=[90,80,60]`，`HSV_HIGH=[125,255,255]`
调H：要选取哪一种颜色调（H过大会把别的颜色也选出来，过小会漏检）     S：控制要不要灰像素（调高会不选择一些浅色背景甚至是白色）   调V：控制允许多暗/多亮的像素（调高会使会有很多地方变黑，调低会使很多地方变成白色）
2. 最小轮廓面积 `MIN_CONTOUR_AREA = 600`
试了几遍发现阈值过高会漏检，过低会发生误检。
